# Changelog

All notable changes to the docs-to-skill plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-14

### Added

- Initial release
- Playwright MCP server (headless) for site navigation and content extraction
- Turndown.js injection for faithful HTML-to-Markdown conversion
- Three discovery strategies: sitemap, navigation crawl, manual URL list
- Subagent-based parallel page fetching
- SKILL.md index generation with reference map and "when to reference" guidance
- Support for personal, project, and plugin output locations

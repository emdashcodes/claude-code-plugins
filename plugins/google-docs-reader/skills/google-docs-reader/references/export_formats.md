# Google Workspace Export Formats

## Supported Document Types

### Google Docs

- **Best format**: DOCX (Microsoft Word)
- **Alternative formats**: PDF, RTF, ODT, TXT, HTML, EPUB
- **URL pattern**: `https://docs.google.com/document/d/{DOC_ID}/export?format=docx`

### Google Sheets

- **Best format**: XLSX (Microsoft Excel)
- **Alternative formats**: PDF, CSV (first sheet only), TSV, ODS, HTML, ZIP (entire workbook as HTML)
- **URL pattern**: `https://docs.google.com/spreadsheets/d/{DOC_ID}/export?format=xlsx`
- **CSV export specific sheet**: Add `&gid={SHEET_ID}` for specific sheet

### Google Slides

- **Best format**: PPTX (Microsoft PowerPoint)
- **Alternative formats**: PDF, ODP, TXT (speaker notes), SVG (individual slides)
- **URL pattern**: `https://docs.google.com/presentation/d/{DOC_ID}/export/pptx`
- **Note**: Slides use `/export/pptx` instead of `?format=pptx`

## File Naming

Downloaded files use Google's default naming:

- **Google Docs**: `{Document Title}.docx`
- **Google Sheets**: `{Spreadsheet Title}.xlsx`
- **Google Slides**: `{Presentation Title}.pptx`

The export script renames files to `{DOC_ID}{extension}` for deterministic handling.

## Document ID Extraction

### From URLs

- Standard edit URL: `https://docs.google.com/document/d/{DOC_ID}/edit`
- Published URL: `https://docs.google.com/document/d/{DOC_ID}/pub`
- Preview URL: `https://docs.google.com/document/d/{DOC_ID}/preview`

The document ID is the alphanumeric string between `/d/` and the next `/`.

### From .gdoc/.gsheet/.gslides Files

These files are JSON with the format:

```json
{
  "": "WARNING! DO NOT EDIT THIS FILE! ANY CHANGES MADE WILL BE LOST!",
  "doc_id": "ACTUAL_DOCUMENT_ID_HERE",
  "resource_key": "",
  "email": "user@gmail.com"
}
```

Extract the `doc_id` field.

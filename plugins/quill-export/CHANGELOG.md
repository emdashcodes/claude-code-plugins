# Changelog

All notable changes to the quill-export plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-07-15

### Added

- Codex plugin manifest and skill interface metadata
- Codex marketplace installation instructions
- Guidance for database access, transcript privacy, ambiguous meeting matches, and optional meeting content

### Changed

- Resolve the bundled export script from the installed skill directory instead of assuming a Claude-specific home path
- Distinguish raw exports from polished meeting notes and require evidence-based summaries and action items

## [1.0.0] - 2025-11-01

### Added

- Initial Quill meeting export skill
- Meeting search, speaker identification, transcript formatting, metadata, notes, and recording links
